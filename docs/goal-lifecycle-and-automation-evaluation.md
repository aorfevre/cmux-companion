We want cmux companion to make each goal’s lifecycle visible, from planning and approval through implementation, review, verification and pull request delivery. The goal view should show the current stage, a timestamped history, blockers and required actions, so we can understand what has happened and what comes next. When defining a goal, we also want to select the planner agent and model, save that choice for the goal, and keep it consistent through planning revisions and retries.

We want to validate this experience with end-to-end tests and an observed run on a real project using real agents. The evaluation should show how much of the flow completes automatically, with screenshots or recordings, stage timings, test results and the resulting changes or pull request. Every approval, clarification, retry, manual fix and recovery action should be recorded, and any failed or untested stage clearly identified. Success means we can see both the goal’s progress and the actual level of automation, supported by evidence from the real-project run.
